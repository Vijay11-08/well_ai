# Project Memory: NeuroNiv

## Initialization Context
- **Date:** September 2026
- **Reference Project:** `https://techlusion.io/`
- **Objective:** Create a visually stunning, AI-Native Engineering Studio landing page.
- **Core Tech Stack:** HTML, CSS, JavaScript, Bootstrap.

## Key Decisions & Rationale
1. **No Frameworks for Phase 1:** Decided to use Vanilla HTML/CSS/JS (with Bootstrap for grids) to keep the initial delivery lightweight, fast, and exactly aligned with the user's explicit request.
2. **Glassmorphism & Gradients:** Adopted heavy use of backdrop-filters and complex radial/linear gradients to match the premium "AI/Web3" aesthetic of the reference site.
3. **Custom Cursor:** Implemented to enhance interactivity and provide a modern, app-like feel on desktop browsers.

## Current State
- **Documentation:** Completed (PRD, Architecture, Rules, Phases, Design, Memory).
- **Frontend Code:** Pending setup of `index.html`, `style.css`, and `main.js`.
